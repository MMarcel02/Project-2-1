you need to have a folder 'builds' and folders 'windows'/'linux'/'macos' inside it (at the project root), where you/we place the builds. The correct build is selected and used based on the OS of the system executing the code:
so visually:
Project-2-1/
├── builds/
│   ├── linux/
│   │   └── 3DBall.x86_64
│   ├── macos/
│   │   └── 3DBall.app
│   └── windows/
│       └── 3DBall.exe
├── runner/
│   ├── configs/
│   │   ├── training/
│   │   │   ├── 3DBall.yaml              # training hyperparameters (default --config)
│   │   │   └── ...
│   │   └── machine_overrides.yaml       # optional, per machine, not committed
│   ├── run_and_log.py
│   └── ...
├── storage/
│   ├── runs.db                          # local database (created on first save)
│   └── ...
└── ...


executing a training is as simple as:
(needs activated virtual environment)
python ./runner/run_and_log.py
since i am using uv (a package manager and more), the command:
uv run ./runner/run_and_log.py
